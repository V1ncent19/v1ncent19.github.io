## 其他不协调之处

1. **英文引语与作品名**：France 正文中约有 13 处被 `“…”` 包围的英文／法文片段，例如 `“New York City”`、`“Vincent”`、整句英文对话；PTES 有 1 处英文引语，Just Because! 的标题使用 `『…』`。中文和英文排版里都可能使用弯双引号 `“…”`，因此仅凭字形无法判定前者错误。需要明确你所说的“英文引号”是 ASCII `"…"`、英文排版弯引号 `“…”`，还是英文书名用斜体／其他方式。日文作品标题是否作为例外也需说明。
2. **中英夹用的括号与大小写**：正文可见 `（p.s. ...）`、`（google map 位置不准）`、`（though it’s ...）`；`Fuego/fuego`、`Acatenango/acatenango`、`Pierre Herme/Pierre Hermé`、`L’eclair/L’éclair`、`Pedra Alta/Pedro Alto` 在不同来源不一致。前一类是括号样式规则，后一类可能涉及原稿或识别事实，不能靠排版脚本修正。
3. **连接符与缩略语**：同站并用 `·`、`-`、`—`、`／`、`/`、`+`、`&`；`etc。`、`btw`、`p.s.`、`i.e.`、`lol` 与中文标点接续方式也不一致。建议区分“行程／章节标题”“正文并列”“数学或配方”“作者口语”，分别定规则。
4. **原文中的空格与笔误**：France 有英文引语 `you should take money  doing this`（双空格）。这类明显排版瑕疵可修；但原话语法、地名拼写和手稿转录应另列核对，不因全站空格规范而顺手润色。
5. **语言镜像**：部分英文路由仍展示中文长篇旅行正文，这是既定内容状态；CV 英文页单条奖项副标题也含中文。前者是翻译范围问题，后者更像漏译；本轮不将其计入空格问题。

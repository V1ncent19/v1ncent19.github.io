## 值得优先尝试的改进

### 1. 照片灯箱尺寸与翻页入口（尺寸已调整；可见翻页按钮暂不采用）

对照了约 0.75、1.23–1.40、1.82 等长宽比的照片后，为灯箱图片增加 1040px 宽、820px 高的上限；中间说明栏继续保持 320–380px。照片仍按原比例完整显示，关闭按钮保留。用户决定暂不加入可见的上一张 / 下一张按钮；键盘左右方向键、Esc 和当前序号继续有效。桌面端验证了竖幅与 1.82 宽幅照片的尺寸布局。窄屏触摸手势尚未单独验证。

相关实现：`components/gallery/gallery-view.tsx`（图片尺寸上限、关闭按钮、灯箱键盘事件与结构）。

### 2. 为窄屏长文提供目录入口

长文的桌面目录在右侧固定显示，带阅读进度和章节跳转；本轮在 12 分钟长文 `/blog/2024/nihongo/` 确认其可见。目录容器使用 `hidden min-[1140px]:block`，因此 1140px 以下完全没有章节目录入口。长文在手机上只能连续滚动，回到前文也不方便。

建议在文章标题或元信息下方放一个可折叠的“目录”按钮，打开后列出章节并跳转；滚动到章节后关闭目录或保留小型当前章节提示。桌面现有时间线可继续使用。

相关实现：`components/blog/post-toc.tsx`。

### 3. 提高旅行日志进度点的可发现性

桌面旅行日志右侧用细小圆点表示日期/章节，点击可跳转，悬停显示标签；正文和地图联动时会显示当前时间/地点。本轮在 PTES 日期导航跳转后确认进度、章节和地图同步更新。点位密集时，单靠圆点不容易看出每个位置代表什么，尤其是巡礼页有 36 个场景。

建议在进度轨道旁持续显示当前章节或日期短标签；扩大点位的可点击区域但不必扩大圆点本身。窄屏顶部日期目录已经存在，重点复核桌面轨道在键盘聚焦和触摸设备上的可用性。

相关实现：`components/travel/TravelNav.tsx`、`components/travel/TravelLog.tsx`。

### 4. 让地图短标签同时具备视觉解释

旅行地图的主题和底图控件在桌面上以“自 / 昼 / 夜”“卫 / 地”等单字呈现。控件有辅助技术名称，但第一次访问者需要猜测缩写含义。

建议为鼠标悬停和键盘聚焦提供一致的小提示；空间允许时加短文字标签。保持地图主体不被控件遮挡，并检查深浅主题下的对比度。

相关实现：`components/travel/TravelMap.tsx`、`components/travel/PilgrimageMap.tsx`。

## 照片 tile 悬浮优化：第一轮（2026-10-24）

范围为 `/travel`、`/travel/zh` 照片墙中的 `GalleryTile`。磨砂信息条展开成主题信息卡的形式、内容、尺寸和灯箱操作保留；旅行日志 StoryTile 的悬浮样式不参与此次改动。

| 动作 | 原实现 | 本轮 |
|---|---|---|
| 信息条/卡片高度与表面 | 进入、离开均 500ms | 进入 280ms，离开 200ms |
| 简略文字 | 300ms 淡出 | 100ms 淡出；收起时稍后恢复 |
| 详细文字 | 随高度裁切露出，无独立淡入 | 延迟 70ms 后在 190ms 内淡入，同时从下方 4px 移入；离开时先淡出 |
| 照片 | 放大至 1.05，700ms | 放大至 1.03，进入 450ms、离开 220ms |
| 整张 tile | 上移 0.25rem | 上移 2px |
| 渐变遮罩 | 500ms | 进入 260ms、离开 180ms |

动画由 `components/gallery/gallery-hover.css` 管理，选择器限制在 `.gallery-photo-tile`。仅对明确的属性应用 transition；悬浮位移使用独立的 `translate`，不覆盖排序 FLIP 的内联 `transform`。键盘 `:focus-visible` 展开相同的主题卡片并保留聚焦环；鼠标悬浮仅在 `(hover: hover) and (pointer: fine)` 下启用，触屏继续点击打开灯箱；减少动态效果时保留信息展开并取消移动和缩放。

本轮通过类型检查、组件 lint、Webpack 静态导出、引用和双语检查。对照素材使用同一批横幅、竖幅与较长信息照片的静止/展开中/展开完成画面，分别覆盖英文浅色与中文暗色。最终浏览器验收通过：两种语言/主题的横幅、竖幅与较长信息样本，键盘 Enter 打开灯箱、Escape 关闭并恢复焦点，随机排序和四列切换后的悬浮，手机纯触屏打开/关闭灯箱且无悬浮残留，以及减少动态效果模式。对照样本的静止和展开后尺寸保持一致；浅色/暗色静止截图一致。修改前后效果图随本轮交付提供。

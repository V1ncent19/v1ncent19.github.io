# 场景与交互

## 设计语言

- 浮空石盘保留暖灰、低反射的石材基调。以树池为圆心排列错缝弧形石板，板心细磨、倒角柔和、缝内粗凿。石板有浅微高低差，倒角和树池也接收彩光。
- 黄铜埋线由同心弧与径向直段组成，转角圆顺，细线贴合石面。由树池向外连接八个窗座，共用段在岔口分流，径向单线留出疏密变化。
- 统一的双面哥特石框以尖拱、单栏主画面、四叶圆饰和两侧小窗格组成。不同深度的凹槽、接缝和暖灰矿纹体现刻石层次。装饰玻璃从各窗主画面取色，透光参与地面和空气渲染。
- 樱花树是全景视觉中心。浅凹树池的树根从粗到细没入土，叶簇随阵风错相摇曳。花瓣可落在树池和石缝附近。远云使用有体积的低多边形云团，环绕镜头轨道外侧，远处随雾变淡。

## 场景接口

| 文件 | 负责的工作 |
|---|---|
| `sundial-layout.ts`、`sundial-inlay.ts` | 槽位、盘面半径、黄铜支路和路径长度 |
| `SundialScene.tsx` | React Three Fiber 渲染入口、自由相机和近景轨道、统一帧循环及后处理 |
| `SundialIsland.tsx`、`sundial-floor.ts`、`sundial-materials.ts`、`sundial-planter.ts` | 石盘、石缝及高度采样、材质、树池、花瓣和窗的网格 |
| `france-window-frame.ts`、`tracery-glass.ts` | 四扇实窗和空窗共用的双面石框，四叶及装饰玻璃 |
| `sundial-optics.ts`、`sundial-pane-paths.ts`、`sundial-hover.ts` | 投影和阴影、玻璃片共享亮暗、悬浮的滑动路径和提亮强度 |
| `SundialSky.tsx`、`SundialAtmosphere.tsx` | 云、天空、全盘日光与近窗彩色散射 |
| `SundialLightMap.tsx`、`sundial-world-light.ts` | 墨卡托控件、晨昏线、时间与地平日月向量 |

世界坐标以 `+X` 为东、`-Z` 为北、`+Y` 为上。日月光位由 Astronomy Engine 按浏览器打开页面的世界时刻计算。初始暂停在赤道日出侧、太阳仰角约 11° 的地点。地图允许在陆地和海上选点；轮廓覆盖南纬 72° 到北纬 84°。改地点会暂停时间并在约 1.15 秒内平滑切光。主动播放每四分钟推进一个日历日，曝光常量为 90%。

窗面、地面和空气彩光取同一日月方向与玻璃片动态。石面材质沿主光线反查窗平面，合成透光、窗框半影和地面细纹。树和窗框为体积散射提供遮挡，低太阳角度下斜照更明显。装饰窗和主画面共用动态透射；夜间由月光决定投影方向，同时保留窗面暖色自发光和树冠的浅粉银蓝亮边。

## 交互与状态

1. 首帧就绪后提供有声与静音入口。有声模式在暖白幕布开始向第一个 i 的圆点收拢时起播。收光显露预先提亮的圆点，随后圆点淡回，控件依次出现。3D 不可用时显示普通游记链接。
2. 主菜单围绕树自由旋转、缩放。轻划树冠给予一次方向推力，回弹时带出一拨花瓣。悬停或聚焦游记时，暖金光从树池沿该窗的埋线扫去，抵达后玻璃与地面彩光一起提亮。离开时沿线路收回，在树池附近渐淡。
3. 点击实窗或底部标题进入近景。底部标题、近景切换箭头、右侧简介随镜头淡变。近景可用左右箭头、滚轮或场景方向键换窗，再点击当前窗进入游记。返回箭头或 Escape 把相机带回上次全景视角，右侧保留简介直至淡出，键盘焦点回到游记导航组。
4. 主菜单右下箭头返回首页。音乐渐弱，暖白光从标题圆点扩至全屏，待首页内容显示后淡出。游记内返回使用公共历史导航，入口为 Playground 时恢复读者之前的近景。
5. 减少动态模式缩短或跳过过渡，保留键盘路径与静音选项。预留空窗框参与光影和布景，交互顺序来自当前实窗清单。

# 场景与交互

## 设计语言

- 浮空石盘保留暖灰、低反射的石材基调。以树池为圆心排列错缝弧形石板，板心细磨、倒角柔和、缝内粗凿。石板有浅微高低差，倒角和树池也接收彩光。
- 黄铜埋线由同心弧与径向直段组成，转角圆顺，细线贴合石面。由树池向外连接八个窗座，共用段在岔口分流，径向单线留出疏密变化。
- 统一的双面哥特石框以尖拱、单栏主画面、四叶圆饰和两侧小窗格组成。不同深度的凹槽、接缝和暖灰矿纹体现刻石层次。装饰玻璃从各窗主画面取色，透光参与地面和空气渲染。
- 实窗和空窗的底座均将最低一层沿原立面向下延伸，底部倒角埋在铺地凹缝以下。可见石面与投影几何使用同样的落脚轮廓，窄接触阴影沿石座侧壁衰减。周围铺地的高低差和接入窗脚的黄铜线保留原几何。
- 樱花树是全景视觉中心。浅凹树池的树根从粗到细没入土，叶簇随阵风错相摇曳。花瓣可落在树池和石缝附近。远云使用有体积的低多边形云团，环绕镜头轨道外侧，远处随雾变淡。

## 场景接口

| 文件 | 负责的工作 |
|---|---|
| `sundial-layout.ts`、`sundial-inlay.ts` | 槽位、盘面半径、黄铜支路和路径长度 |
| `SundialScene.tsx` | React Three Fiber 渲染入口、自由相机和近景轨道、统一帧循环及后处理 |
| `SundialIsland.tsx`、`sundial-floor.ts`、`sundial-materials.ts`、`sundial-planter.ts` | 石盘、石缝及高度采样、材质、树池、花瓣和窗的网格 |
| `france-window-frame.ts`、`tracery-glass.ts` | 四扇实窗和空窗共用的双面石框，四叶及装饰玻璃 |
| `sundial-optics.ts`、`sundial-pane-paths.ts`、`sundial-hover.ts` | 投影和阴影、玻璃片共享亮暗、悬浮的滑动路径和提亮强度 |
| `SundialSky.tsx`、`SundialAtmosphere.tsx` | 云、天空、全盘日光与近窗彩色散射 |
| `SundialLightMap.tsx`、`sundial-world-light.ts` | 墨卡托控件、晨昏线、时间与地平日月向量 |

世界坐标以 `+X` 为东、`-Z` 为北、`+Y` 为上。日月光位由 Astronomy Engine 按浏览器打开页面的世界时刻计算。初始暂停在赤道日出侧、太阳仰角约 11° 的地点。地图允许在陆地和海上选点；轮廓覆盖南纬 72° 到北纬 84°。改地点会暂停时间并在约 1.15 秒内平滑切光。主动播放每四分钟推进一个日历日，曝光常量为 90%。

窗面、地面和空气彩光取同一日月方向与玻璃片动态。石面材质沿主光线反查窗平面，合成透光、窗框半影和地面细纹。树和窗框为体积散射提供遮挡，低太阳角度下斜照更明显。装饰窗和主画面共用动态透射。夜间由月光决定投影方向，石盘在月光穿过玻璃的区域补少量同色漫反射，亮度仍随月相、月亮高度和遮挡变化。窗面保留暖色自发光，树冠保留浅粉银蓝亮边。

入夜时从侧上方渐入银蓝色天空补光，勾出石盘、窗框和树冠的轮廓。补光无投影。随着可见月光增强，补光平滑减弱，由带真实阴影的月光主导石面和窗框两侧的明暗。石盘和石窗框将直射月光的漫反射调整为银蓝色，并保持其线性亮度；玻璃投影和黄铜镶线保留原色。云层淡出日光亮边，近处云只留很弱的散射亮缘。每扇实窗复用原有点光，夜间下移到窗脚内侧，在附近石面留下短距离的暖色反光。玻璃接收这组点光的漫反射，滤掉尖锐的镜面亮点。无月夜保留完整的天空补光和窗脚反光。

全景相机转动或缩放期间，体积光使用原采样宽高的 75%，仍按深度插值回主画面。停稳约 130 ms 后恢复采样尺寸。主画面分辨率和阴影贴图尺寸保持原值。全景移动且主光方向固定时，阴影贴图每隔约 48 ms 更新一次，保留树冠随风摆动的影子。摇树、改变主光方向或进入近景时恢复逐帧更新。

## 交互与状态

1. 首帧就绪后提供有声与静音入口。入场时欢迎标题与按钮先淡出，随即暖白幕布向场景标题第一个 i 的圆点收拢，从边缘逐渐露出已渲染的 3D 场景。幕布软边外侧的暖光拖尾与幕布共享收拢半径和缓动曲线，靠近圆点时渐淡，由圆点周围的暖金余晖接续。幕布结束后控件即可操作，余晖继续扩散并在约 0.6 秒内淡去。有声模式在入场过渡开始时起播。3D 不可用时显示普通游记链接。

   加载中的 Gathering light… 使用独立的 `inline-block` 文字图层和 `will-change: opacity`，以 4.4 秒周期平滑呼吸（45% 时达到亮点，余下时间渐暗）。动画只改变透明度，让场景初始化期间也能由合成线程继续更新。首帧就绪后，暖白幕布居中呈现两行欢迎语，第一行是 Welcome to my TravelLog Garden，第二行是 Atelier du Vitrail，下方是两个入口。窄屏允许标题与按钮自然换行，并按右侧折叠面板的同一条件在按钮下显示桌面浏览建议。减少动态模式保持静态加载文字，并跳过幕布收拢动画。

2. 主菜单围绕树自由旋转、缩放。普通滚轮按输入步幅直接调整全景相机距离，约 100 像素的输入对应约 9% 的距离变化。按住拖拽时，镜头朝指针目标方向以 20 ms 的时间常数平滑跟随，方位和俯仰的合成角度差最多 1.5°。松手时从当前画面角度起步，依据最后一次指针转动保留最多 140 ms 的减速惯性，幅度不超过约 6°。停住后再松手或开始新手势时不滑行，开启减少动态时直接跟随指针。从树冠起手会固定镜头并给予树一次方向推力，回弹时带出一拨花瓣。悬停或聚焦游记时，暖金光从树池沿该窗的埋线扫去，抵达后玻璃与地面彩光一起提亮。离开时沿线路收回，在树池附近渐淡。
3. 点击实窗或底部标题进入近景。底部标题、近景切换箭头、右侧简介随镜头淡变。近景可用左右箭头、滚轮或场景方向键换窗，再点击当前窗进入游记。穿窗的折射在同一位置采样完整颜色，空气散射随运镜淡出。返回箭头或 Escape 把相机带回上次全景视角，右侧保留简介直至淡出，键盘焦点回到游记导航组。
4. 主菜单右下箭头返回首页。音乐渐弱，暖白光从标题圆点扩至全屏，待首页内容显示后淡出。游记内返回使用公共历史导航，入口为 Playground 时恢复读者之前的近景。
5. 减少动态模式缩短或跳过过渡，保留键盘路径与静音选项。预留空窗框参与光影和布景，交互顺序来自当前实窗清单。
6. 窄屏（720 px 及以下）或矮触屏（高度 500 px 及以下）默认收起右侧面板。右上圆形按钮展开或收起地图、音乐、署名与近景简介。展开内容可内部滚动，留出底部游记导航的操作空间。Escape 优先收起面板，再次按下时退出花窗近景。桌面右侧面板常显。

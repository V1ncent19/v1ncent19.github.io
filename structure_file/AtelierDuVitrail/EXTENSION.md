# 扩展与验收

## 加入一篇游记

1. 在 `content/travel/<tripId>/` 和双语 `app/travel/` 路由完成该篇游记。用公共旅行日志框架。相关字段与验收见 [旅行日志手册](../FEATURE_TRAVEL_LOG.md)。
2. 把绘稿放入 `assets-src/playground/`。取原图最可辨认的构图和主色，用能切割和拼接的玻璃片组织画面。明确主窗尖拱、裁切范围和铅条，少量线条即可交代结构。加入 `window-gallery.mjs`，为装饰格配色则更新 `tracery-palettes.json`。
3. 在 `travelogues.json` 添加唯一 `id`，选择已有空位 `ring-1-02`、`04`、`06` 或 `08` 中的一处，设置 `assetId`、`tripId`、`label` 和可选摘要。读者的切换顺序跟随清单，环上位置跟随 `slotId`。
4. 重建玻璃图集与邻接数据，运行 `node scripts/check-playground-sundial.mjs`。浏览器对照正面、背面和低月视角，核对配准、装饰格、地面彩光和共享支路。再走一遍近景、进入游记、返回原窗的交互。

## 扩展外环

首圈是半径 11.8 的 B 版八向布局，窗座从圆心错开到 7.05–9.87。先填首圈，再用 `ring-2-01` 起的外环槽位。当前环号从 1 到 8，每圈相比上一圈多四个槽位，外环间距 4.35。软件能求出位置与盘面半径，外环布局仍应验收窗间净距、遮挡、默认全景构图和埋线转折。

增加窗数时要核对图集长度和 GPU 负载。当前主窗图集宽度为 887 × 玻璃资产数，八个资产为 7096 px，十二个为 10644 px。超过目标设备的纹理尺寸限制时应先调整图集布局及全部采样入口，再增加资产。光学着色器同时按可见窗与空窗增加采样，扩环时在桌面和普通笔记本上分别测日间、斜照与近景。

## 验收顺序

- 先跑 `node scripts/check-playground-sundial.mjs`、`npm run check:refs`、`npm run check:i18n` 和站点静态构建。手工内容、入库派生数据、源码素材和发布资源按 [数据边界](ASSETS.md) 分层。
- 浏览器核对中英文主导航、首页悬浮封面、旅行页简介排序和链接。入口共用 `/playground/`，该页的界面语言为英语，标题为法语。
- 用同一机位对照晨光、日间、斜照和月夜；检查窗框掠射影、彩光边缘、四叶格动画、石板纹路以及树冠和云的遮挡。
- 验证快进快退、快速换窗、键盘焦点、减少动态、静音与有声入口、WebGL 失败兜底。试走主菜单回首页，以及分别从首页、Blog、Travel 和 Playground 进入游记后返回。直接访问游记应回落到对应语言的 Travel。
